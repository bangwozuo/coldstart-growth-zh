### 示例 1：社区热帖洞察

**能力**：抓取并摘要指定 subreddit/话题热帖，提炼痛点与情绪

**输入**：

```json
{
  "source": "r/SideProject 近 7 天热帖 20 条"
}
```

**输出**：

## 采集结果

| # | 标题 | 来源 | 时间 | 关键信息 |
|---|------|------|------|---------|
| 1 | 独立开发者的 30 天 | r/SideProject | 09-28 | 日更内容带来 1200 访问 |
| 2 | 我的第一个付费用户 | r/SideProject | 09-27 | 转化来自 Reddit 评论 |

## 概要

近期热帖集中在「冷启动获客」与「定价策略」两类话题，情绪整体偏积极。

**资产位置**：`skills/community-post-insight/`

### 示例 2：痛点卖点匹配

**能力**：将社区痛点与产品功能映射为钩子文案

**输入**：

```json
{
  "brief": "面向独立开发者的性能优化工具，主打启动速度从 8 秒降到 0.3 秒"
}
```

**输出**：

## 钩子文案

我们花了 3 个月，把启动时间从 8 秒压到 0.3 秒。

## 切入角度

用具体的数字对比制造冲击力，开发者对性能数字高度敏感。

## 目标受众

关注性能优化的独立开发者与前端工程师。

**资产位置**：`skills/painpoint-sellingpoint-match/`

### 示例 7：周度数据复盘

**能力**：多平台数据汇总归因与下周建议

**输入**：

```json
{
  "data": {
    "曝光": 12000,
    "点击": 480,
    "转化": 32
  }
}
```

**输出**：

## 核心结论

本周曝光增长 62% 来自 Reddit 单帖爆发，其余渠道基本持平。

## 驱动因素

1. **Reddit 热帖** — 贡献 62% 增量，帖子进入 subreddit 首页
2. **X 转发** — 贡献 18%，主要来自 2 个 KOL 转发
3. **自然搜索** — 贡献 12%，长尾词开始见效

## 置信度

**中** — 数据来源为用户手动导出，样本周期仅 1 周

## 下一步行动

1. 拆解那条 Reddit 热帖的结构（标题 / 首段 / 配图 / 发布时间）
2. 下周复用该结构发 3 篇，验证可复制性
3. X 侧主动联系 5 个同领域 KOL，建立长期关系

**资产位置**：`skills/weekly-data-review/`
